# DRESSD

> Une garde-robe numérique interactive pour organiser ses vêtements et créer ses outfits.

DRESSD est une application web permettant de **numériser, organiser et exploiter sa garde-robe**.

L'objectif est de proposer une alternative simple et visuelle à la gestion traditionnelle de ses vêtements : enregistrer ses pièces, savoir où elles se trouvent, les retrouver facilement et composer des tenues à partir de sa propre garde-robe.

---

## ✦ Le projet

Posséder beaucoup de vêtements peut rapidement rendre leur gestion compliquée.

Certains sont dans l'armoire, d'autres chez son partenaire, dans une valise ou au linge sale. Il peut également être difficile de se souvenir de toutes les pièces que l'on possède ou de trouver de nouvelles associations entre elles.

**DRESSD centralise toutes ces informations dans une seule application.**

L'utilisateur peut ainsi :

- 📦 enregistrer ses vêtements
- 📍 savoir où ils se trouvent
- 🏷️ les organiser avec des catégories et des tags
- 🔎 les rechercher et les filtrer
- ⭐ ajouter ses pièces préférées aux favoris
- 👕 créer des outfits à partir de sa garde-robe
- 📸 conserver des photos de tenues réellement portées

---

# 🚀 V1 — MVP

La première version se concentre sur les fonctionnalités essentielles.

## 👕 Gestion des vêtements

L'utilisateur peut ajouter un vêtement à sa garde-robe avec différentes informations :

- Photo
- Nom
- Catégorie
- Couleur
- Taille
- Marque
- Tags
- Localisation

### Catégories initiales

- Haut
- Bas
- Robe
- Veste / Manteau
- Chaussures
- Accessoire

Les catégories pourront évoluer par la suite.

---

## 📍 Localisation

Chaque vêtement possède une localisation permettant de savoir où il se trouve physiquement.

Exemples :

- Armoire
- Chambre
- Commode
- Linge sale
- Chez mon copain
- Chez ma sœur
- Chez mes parents
- Valise
- Autre

L'utilisateur pourra également créer ses propres localisations.

> La localisation permet notamment de déterminer si un vêtement est réellement disponible sans avoir besoin d'un statut "disponible / indisponible".
